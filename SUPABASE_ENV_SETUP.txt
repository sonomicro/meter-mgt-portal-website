╔═══════════════════════════════════════════════════════════════════════════╗
║                              TROUBLESHOOTING                              ║
╚═══════════════════════════════════════════════════════════════════════════╝

Can't find "Environment Variables" tab?
  → Try: Settings → Secrets
  → Try: Function Details → Configuration
  → Look for a gear icon ⚙️ or settings icon

Variables not showing after save?
  → Wait 30 seconds and refresh the page
  → Check the edge function logs for errors

Still getting 404 errors?
  → Double-check variable names (exact case matters!)
  → Verify no extra spaces in values
  → Ensure you copied the FULL secret value

Edge function status shows error?
  → Click on the function to view logs
  → Look for "Notehub credentials not configured"
  → This means variables weren't saved correctly

╔═══════════════════════════════════════════════════════════════════════════╗
║                            WHAT HAPPENS NEXT                              ║
╚═══════════════════════════════════════════════════════════════════════════╝

Once variables are set:

  1. Edge function reads NOTEHUB_CLIENT_ID and NOTEHUB_CLIENT_SECRET
  2. Edge function authenticates with Notehub using OAuth2
  3. Edge function proxies requests from your frontend
  4. Devices load successfully in your application!

Flow:
  Browser → Supabase Auth → Edge Function → Notehub OAuth2 → Notehub API
